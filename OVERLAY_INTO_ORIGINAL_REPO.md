# How to merge this package into the original repository

1. Back up your current repository.
2. Extract this ZIP.
3. Copy its contents into the root of:
   `K3-Track3-Lab19-2A202601323-NgoThanhDat`
4. Allow the completed notebook and helper/report files to replace same-name student deliverables.
5. **Do not delete or replace** the instructor `README.md`, `ASSIGNMENT.md`, `RUBRIC.md`, or Golden CSV/XLSX files.
6. Keep your local `.env`; it is intentionally not included here.
7. Run `tools/smoke_services.py`.
8. Run the notebook from a clean kernel.
9. Run `tools/generate_reports.py`.
10. Run `tools/validate_submission.py`.
11. Review `git status --short` and only then commit/push.
